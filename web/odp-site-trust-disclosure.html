The read ABI decodes prior contractVersion values on-chain. The verifier uses the primary deployment first; if a record is missing, it tries previousContracts (older deployments — separate registries).

Verify can read a local .odpass ZIP: it canonicalizes passport.json against on-chain dataHash. Sidecar files live under originals/; exact paths are in manifest.originals (bundle v0.3). The page hashes those bytes like mint and may show a local raster preview when a hash matches — the file is not uploaded. Legacy bundles with separate original/ and image/ folders are still accepted.

0.x site releases are red-flag (experimental). Stable SemVer starts at major 1. When several stable majors exist, any major below the latest stable is yellow-flag — verify upgrade notes.

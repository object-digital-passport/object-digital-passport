The checker talks to the main registry first. If a record isn’t there, it may look at older registry addresses you configured — useful when data moved between deployments.

Verify can open a .odpass file on your computer (it’s a ZIP). Inside is passport.json. The page checks that this file still matches what was saved in the public registry (a fingerprint of the data). Extra files (original artwork, pictures) sit in the originals/ folder; the bundle lists their paths. Previews are built on your device — nothing is uploaded to this website. Older bundle layouts still work.

0.x site releases are experimental (red flag). Stable numbering starts at major 1. If several stable lines exist, older majors are a yellow flag — read upgrade notes.

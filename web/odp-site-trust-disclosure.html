Lookups use the main registry first. If there’s no match, you can fall back to older registry addresses from settings — useful when data moved between deployments.

On Verify, you can open a .odpass file from your device (it’s a ZIP). It contains passport.json; the page checks it against the public record. Extra files live under originals/. Hashing and previews run in your browser — files are not uploaded to this site. Older bundle layouts still work.

Site version 0.x means experimental builds (🚩 red flag). Stable releases start at 1.0. If several stable lines exist, an older major can be a yellow flag — read the release notes.

Creator ID Passport Verify

Passport IDs start with ODP-. Creator IDs look like C-123-456-789-012 (also B-, P-, or M-). You can paste text from a label, a link from this site, or tap the square button to scan a QR code.

Creator wallet proof (EIP-191)

Separate tool from registry verify above: prove control of the creator wallet for a passport — no gas. The recovered signer must match passport.creator on-chain. This is key control, not legal authorship.

Connect the creator wallet, enter the passport Human ID, then sign. Copy the message + signature or the JSON bundle for the verifier.

Paste the exact message and signature from the creator. The page checks EIP-191 recovery against the passport’s on-chain creator (needs RPC + NET.contract).

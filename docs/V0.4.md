# ODP v0.4 — pointer

The **v0.4** line on **`main`** includes **on-chain** generation **4** (`CONTRACT_VERSION` packed byte **4**), optional **`ODPCounterfeitConcern`** satellite, **`ObjectDigitalPassport`** with slimmer public ABI, plus **static web** (WalletConnect, session restore) and **SPEC** updates. **Published default Polygon addresses** in [`README.md`](../README.md) may still match an earlier **generation 3** deployment until you redeploy and update **`NET.*`**.

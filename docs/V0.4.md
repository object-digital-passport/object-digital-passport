# ODP v0.4 — pointer

*Plain-language summary of this version: [**v0.4 release note**](releases/v0.4.md). This page is the long-form detail behind it.*

The **v0.4** line on **`main`** includes **on-chain** generation **4** (`CONTRACT_VERSION` packed byte **4**), optional **`ODPCounterfeitConcern`** satellite, **`ObjectDigitalPassport`** with slimmer public ABI, plus **static web** (WalletConnect, session restore) and **SPEC** updates. **Default Polygon addresses** in [`README.md`](../README.md) and `chain/deploy/deployments/polygon.json` (written locally at deploy time; not committed) match the **generation 4** deployment wired into static-page **`NET.*`**.

Long-form notes for this line were written in Russian first (`web/frontend/localization/ru/RELEASE_v0.4.md`). Later lines have English notes too — `docs/RELEASE_v0.4.1.md`, `docs/RELEASE_v0.6.md` — and every version now has a short English release note under `docs/releases/`.

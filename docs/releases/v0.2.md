# ODP v0.2 — no fees, and fewer things forced on you

ODP is a free, open digital passport for real objects — art, limited runs, archives — that anyone can verify. Forever.

**New here?** [What this is](https://github.com/object-digital-passport/object-digital-passport#readme) · [Verify something — free, no wallet](https://object-digital-passport.github.io/object-digital-passport/verify.html)

## What changed

- **Registering costs only the network fee.** The protocol itself takes nothing, and never will. On Polygon that is roughly one to three cents.
- **You no longer have to publish a file to register.** You can register an object first and add the public link later, without the record changing.
- **Anti-spam limits per wallet, per month** — about a thousand registrations for an individual, a hundred thousand for a brand. Enough that you will not notice unless you are flooding the registry.

## Do I need to do anything?

- **You already registered a passport** — nothing. Records from 0.1 stay where they are and stay readable.
- **You are about to register one** — use this version rather than 0.1.
- **You run your own copy** — the contract changed, so this is a new deployment, not an upgrade of the old one.

## Status

Alpha. Each version is a separate registry and passports do not move between them, so anything registered here is a record on that version's registry and nowhere else. For work you need to last decades, wait for v1 — target January 2027.

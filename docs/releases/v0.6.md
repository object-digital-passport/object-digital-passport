# ODP v0.6 — what a passport stores, redesigned

ODP is a free, open digital passport for real objects — art, limited runs, archives — that anyone can verify. Forever.

**New here?** [What this is](https://github.com/object-digital-passport/specifications#readme) · [Verify something — free, no wallet](https://object-digital-passport.github.io/verify.html)

**Live on the Polygon network since 24 July 2026.** The previous tagged release was v0.4.1 — v0.5 was deployed and never released, and the reason is written down in [its own note](https://github.com/object-digital-passport/specifications/blob/main/docs/releases/v0.5.md).

## What changed

- **An object is now readable straight from the registry.** Its title, its author, and a one-line description live on the blockchain itself, so you can see what something is without downloading a file. Written once, at registration, with no way to edit afterwards.
- **A passport will not be issued without real identifying detail.** A physical object needs a photograph, measurements, materials, and the distinguishing marks a copy would not reproduce. A record without those proves nothing about the thing in front of you, so the registry now refuses it.
- **History can only be added to.** The previous version let an owner overwrite a passport's status, location, condition and rights. All of that is gone: changes are now entries appended to a list, and the current state is simply the most recent entry. Nothing is overwritten and nothing is lost.
- **Tamper-evident seals became optional.** A chip or a numbered seal is now something you add on top of the identifying detail, recommended for valuable objects rather than demanded of everything.

## Do I need to do anything?

- **You already registered a passport** — nothing. Records on earlier registries stay readable and the check page still finds them.
- **You are about to register one** — use this version. It is where new passports go.
- **You run your own copy** — this is a new deployment, not an upgrade. Point your pages at the new address.

# ODP v0.3 — passports gained an owner

ODP is a free, open digital passport for real objects — art, limited runs, archives — that anyone can verify. Forever.

**New here?** [What this is](https://github.com/object-digital-passport/object-digital-passport#readme) · [Verify something — free, no wallet](https://object-digital-passport.github.io/verify.html)

## What changed

- **A passport now has an owner, and ownership can be handed over.** Before this, a passport belonged permanently to whoever created it, which does not match what happens when an object is sold.
- **A passport can be withdrawn.** If a record is wrong, its issuer can mark it as withdrawn — permanently and visibly, rather than by deleting it.
- **Someone else can be allowed to update your public links** without being able to issue passports in your name.
- **Institutions can be linked to each other** — a gallery and its parent organisation, for example — with both sides having to agree.

## Do I need to do anything?

- **You already registered a passport** — nothing. Earlier records remain readable; the check page still finds them.
- **You are about to register one** — use this version.
- **You run your own copy** — this is a new deployment. Some parts moved into separate helper contracts that have to be deployed alongside the main one.

## Status

Alpha. Each version is a separate registry and passports do not move between them, so anything registered here is a record on that version's registry and nowhere else. For work you need to last decades, wait for v1 — target January 2027.

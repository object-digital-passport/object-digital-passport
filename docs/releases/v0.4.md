# ODP v0.4 — honest dates, and a way to flag a fake

ODP is a free, open digital passport for real objects — art, limited runs, archives — that anyone can verify. Forever.

**New here?** [What this is](https://github.com/object-digital-passport/object-digital-passport#readme) · [Verify something — free, no wallet](https://object-digital-passport.github.io/object-digital-passport/verify.html)

## What changed

- **The date in a passport's identifier is now the real one.** An earlier build let the issuer put any month in it. That build was stopped before anyone relied on it, and the fix landed before this version was used for real objects.
- **Institutions can raise a counterfeit concern** against a passport — visible to everyone checking it. It is an expert's opinion on the record, not a verdict, and only the institution that raised it can withdraw it.
- **Staying signed in stopped breaking.** Reconnecting a wallet no longer loses the session halfway through registering something.

## Do I need to do anything?

- **You already registered a passport** — nothing. Earlier records stay readable.
- **You are about to register one** — use this version or later.
- **You run your own copy** — new deployment. The counterfeit-concern contract is optional; the main registry works without it.

## Status

Alpha. Each version is a separate registry and passports do not move between them, so anything registered here is a record on that version's registry and nowhere else. For work you need to last decades, wait for v1 — target January 2027.

# ODP v0.4.1 — website and tooling only

ODP is a free, open digital passport for real objects — art, limited runs, archives — that anyone can verify. Forever.

**New here?** [What this is](https://github.com/object-digital-passport/specifications#readme) · [Verify something — free, no wallet](https://object-digital-passport.github.io/verify.html)

## What changed

Nothing on the blockchain. This release is the website, the tooling and the documentation — the registry is untouched, and the version of the protocol is still 0.4.

- **The pages now verify the code they load from other people's servers.** If a third-party library were ever swapped for a tampered copy, the browser refuses it instead of running it.
- **Clearer ways to report things** — issue templates for a bug, a feature, a gap in the specification.
- **Dependency and typing cleanup** behind the scenes.

## Do I need to do anything?

- **You already registered a passport** — nothing. Nothing on the blockchain changed.
- **You are about to register one** — nothing. Same registry as 0.4.
- **You run your own copy** — pull the updated pages if you host them yourself. No redeployment needed.

## Where it lives

Same registry as 0.4. Current addresses for every version: [deployment table](https://github.com/object-digital-passport/specifications/blob/main/docs/GUIDE.md#current-release).

## Status

Alpha. Each version is a separate registry and passports do not move between them, so anything registered here is a record on that version's registry and nowhere else. For work you need to last decades, wait for v1 — target January 2027.

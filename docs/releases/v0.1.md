# ODP v0.1 — the first working version

ODP is a free, open digital passport for real objects — art, limited runs, archives — that anyone can verify. Forever.

**New here?** [What this is](https://github.com/object-digital-passport/object-digital-passport#readme) · [Verify something — free, no wallet](https://object-digital-passport.github.io/verify.html)

## What changed

This is the beginning — there was nothing before it.

- A **registry** on the Polygon network: a public list that records who registered what, and when. Nobody owns it and nobody can quietly edit it.
- Three pages you can open in a browser: create an identity, register an object, check an object.
- A written specification, so anyone can build their own version of all of this.

## Do I need to do anything?

- **You already registered a passport** — nothing to do. This is the first release.
- **You are about to register one** — read the specification first. This is early work and it changes.
- **You run your own copy** — the deploy scripts and the command-line tool are in the repository.

## Status

Alpha. Each version is a separate registry and passports do not move between them, so anything registered here is a record on that version's registry and nowhere else. For work you need to last decades, wait for v1 — target January 2027.

# Профиль Object ID — документирование для возврата

> [🇬🇧 English](Object-ID-Profile) · 🇷🇺 **Русский**

[Object ID](https://icom.museum/en/resources/standards-guidelines/objectid/) — международный чек-лист (ICOM), по которому музеи, полиция, ИНТЕРПОЛ и страховые описывают культурные объекты, чтобы их можно было опознать и вернуть после кражи. Паспорт ODP может нести полный чек-лист — с криптографической меткой времени.

> ODP *совместим с* чек-листом Object ID. Проект не аффилирован с ICOM и не сертифицирован им.

## Один документ — две задачи

- **Подлинность:** хэши, пломбы и институциональные подтверждения отвечают на вопрос «передо мной зарегистрированный оригинал?»
- **Возврат:** чек-лист отвечает на вопрос «можно ли опознать объект, если он исчезнет?» — а те же *отличительные особенности* (тот самый отреставрированный разрыв, та пометка мелом на подрамнике) помогают эксперту отличить оригинал от копии. QR-код подделыватель склонирует; задокументированный трёхсантиметровый ремонт — уже вряд ли.

## Девять категорий → поля паспорта

| Object ID спрашивает | Вы заполняете |
| --- | --- |
| Тип объекта | `domain`, `physical.category` |
| Материалы и техника | `physical.medium`, `physical.materials` |
| Размеры | `physical.dimensions`, `physical.weight` |
| Надписи и клейма | `physical.marks` |
| **Отличительные особенности** | `objectId.distinguishingFeatures` — повреждения, ремонты, дефекты; пишите так, чтобы посторонний мог сверить |
| Название | `title` |
| **Сюжет** | `objectId.subject` — что изображено («зимний пейзаж с мельницей…») |
| Дата или период | `creationDate` |
| Автор | `authorship.author` |
| + Фотография | `image` — под профилем **обязательна** |

## Держите в секрете, пока не понадобится

Практика Object ID: документацию хранить надёжно и раскрывать по инциденту. ODP это умеет из коробки:

1. Минтите с **пустой публичной ссылкой** — в блокчейн уходят только отпечатки; фото и особенности остаются в вашем приватном `.odpass`.
2. Если объект украден — передайте `.odpass` полиции и реестрам (или опубликуйте).
3. Любой сможет сверить документацию с **докражными** on-chain отпечатками и меткой времени: описание доказуемо не придумано задним числом.

И никогда не пишите адрес хранения объекта в публичные поля паспорта — см. [правила приватности](https://object-digital-passport.github.io/object-digital-passport/spec/#privacy-of-current-state-fields-normative).

# Быстрый старт

> 🌐 [English](Quick-Start) · **Русский**

## Проверить объект (без кошелька, бесплатно, 2 минуты)

1. Откройте [страницу проверки](https://object-digital-passport.github.io/object-digital-passport/demo/verify.html).
2. Введите Passport ID с объекта (вида `ODP-2026-03-004829301`) или отсканируйте QR-код.
3. Читайте результат: страница получает запись из блокчейна, скачивает бандл паспорта (если издатель его разместил) и сравнивает криптографические отпечатки.
4. **Обязательно сделайте и человеческий шаг:** найдите ID профиля издателя (вида `C-482-930-174-005`) на его **официальном сайте или в соцсетях**. Блокчейн доказывает, что запись существует, — публичная репутация издателя доказывает, кто за ней стоит.

Если у вас есть файл `.odpass` (ZIP, который выдаёт создатель) — перетащите его на страницу проверки: работает и без публичного хостинга.

## Зарегистрировать профиль (один раз, ~$0.01)

1. Заведите криптокошелёк (MetaMask или аналог) — **отдельный, только для ODP**, не тот, где сбережения.
2. Пополните его небольшим количеством POL в сети Polygon (пары центов хватит надолго).
3. Откройте [страницу профиля](https://object-digital-passport.github.io/object-digital-passport/demo/creator.html), подключите кошелёк, выберите тип:
   - **C** — автор (художник, фотограф, мастер)
   - **B** — бренд или студия
   - **P** — доказывающая институция (эксперты, аукционные дома)
   - **M** — музей или коллекция
4. Вы получите постоянный ID профиля. **Опубликуйте его на своём сайте и в соцсетях** — на видном месте. Эта публичная связка и делает ваши паспорта заслуживающими доверия.

## Выпустить первый паспорт (~$0.01)

1. Откройте [страницу паспорта](https://object-digital-passport.github.io/object-digital-passport/demo/passport.html) и подключите зарегистрированный кошелёк.
2. Опишите объект: название, описание, фото, физические детали (материалы, размеры, клейма) и — рекомендуем — [поля Object ID](Object-ID-Profile-ru) (сюжет, отличительные особенности).
3. Физическому объекту нужна **пломба**: номерная защитная наклейка или NFC-чип (см. [NFC-пломбы](NFC-Seals-ru)).
4. Минтите. В блокчейн попадают только отпечатки (хэши) — фото и детали остаются в вашем файле `.odpass`.
5. **Скачайте и храните `.odpass`.** Это полное содержимое паспорта; цепочка хранит лишь его отпечаток. Разместите файл публично (тогда проверка работает через веб) или держите приватно и передавайте по запросу.
6. Нанесите Passport ID на объект: печатью, QR-кодом или NFC.

## Золотые правила

- 📁 **Не теряйте `.odpass`** — блокчейн его не восстановит.
- 🔑 **Не теряйте кошелёк** — профиль не восстанавливается (уже выпущенные паспорта остаются действительными).
- 📢 **Публикуйте ID профиля** на каналах, которые контролируете, — это якорь доверия.
- 🗺️ **Не указывайте точное местонахождение в on-chain полях** — изменяемое состояние публично навсегда ([правила приватности](https://object-digital-passport.github.io/object-digital-passport/spec/#privacy-of-current-state-fields-normative)).

# Добро пожаловать в Object Digital Passport 👋

> 🌐 [English](Home) · **Русский**

**Object Digital Passport (ODP)** — открытый стандарт цифровых паспортов для реальных вещей: произведений искусства, лимитированных изделий, архивных документов. Паспорт может проверить любой человек — бесплатно, навсегда. Без компании-посредника и подписок: только публичный реестр в блокчейне Polygon и открытые инструменты.

Паспорт доказывает три вещи:

1. **Когда** объект был зарегистрирован (метка времени блокчейна),
2. **Кто** его зарегистрировал (публичный ID профиля, который можно сверить с официальным сайтом издателя),
3. **Что описание не менялось** с момента регистрации (криптографические отпечатки — хэши).

А с профилем, совместимым с Object ID, тот же паспорт служит **документацией для розыска** — для полиции, страховых и реестров украденного.

# Устройство репозитория

*Перевод справочно. Нормативный оригинал — только на английском: [`docs/REPOSITORY_LAYOUT.md`](../REPOSITORY_LAYOUT.md). Этот текст может содержать ошибки; при расхождении верен английский.*

Этот репозиторий — **сам протокол**: спецификация, реализующие её контракты, а также схема и
векторы, которые делают её проверяемой. Эталонный сайт лежит в отдельном репозитории.

| Путь | Роль |
|------|------|
| [`SPEC.md`](../../SPEC.md) | **Нормативный** протокол, по-английски, в корне репозитория |
| [`schema/`](../../schema/) | JSON Schema, примеры соответствия и контрольные векторы |
| [`chain/`](../../chain/) | Solidity, тесты Hardhat, скрипты деплоя, `mint.py` |
| [`docs/`](../README.md) | Проектные записки, журнал решений, модель безопасности, заметки к релизам |
| [`docs/ru/`](.) | Русские переводы — справочные; нормативен текст `SPEC.md` |
| [`tools/`](../../tools/) | Отрисовывает спецификацию в публикуемые страницы `/spec/` |

## Что лежит в других местах

| | |
|---|---|
| **Эталонный сайт** | [object-digital-passport.github.io](https://github.com/object-digital-passport/object-digital-passport.github.io) — страницы на <https://object-digital-passport.github.io/> и всё, что работает в браузере |
| **Приложение ODP для iOS** | `ios-app` — выпускает, носит и проверяет паспорта; сканирует NFC-пломбы. **Приватен, пока не вышел**, поэтому имя дано без ссылки |
| **Android-верификатор** | `android-verifier` — NFC-верификатор, начатый и не доведённый. Приватен и не является эталонной реализацией чего-либо |

Разделение намеренное. Стандарт, который едет внутри одной реализации, читается как
документация этой реализации, а эти двое переплелись настолько, что публикацией спецификации
занимался деплой сайта. Теперь они разделимы, и ничто здесь не лезет в сайт.

## Команды

```bash
cd chain && npm install && npm run compile && npm test   # контракты
node tools/build-spec.mjs _site/spec                     # отрисовать спецификацию
node chain/tools/lint_release_notes.mjs                  # стиль заметок к релизам
```

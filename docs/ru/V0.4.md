# ODP v0.4 — указатель

*Перевод справочно. Нормативный оригинал — только на английском: [`docs/V0.4.md`](../V0.4.md). Этот текст может содержать ошибки; при расхождении верен английский.*

*Краткое изложение этой версии человеческим языком: [**заметка к релизу v0.4**](../releases/v0.4.md). Эта страница — развёрнутые подробности за ней.*

Линия **v0.4** в **`main`** включает **on-chain** поколение **4** (упакованный байт `CONTRACT_VERSION` **4**), опциональный спутник **`ODPCounterfeitConcern`**, **`ObjectDigitalPassport`** с более тонким публичным ABI, а также **статический веб** (WalletConnect, восстановление сессии) и правки **SPEC**. **Адреса Polygon по умолчанию** в [`README.md`](../../README.md) и `chain/deploy/deployments/polygon.json` (пишется локально во время деплоя, в репозиторий не коммитится) соответствуют деплою **поколения 4**, проведённому в **`NET.*`** статических страниц.

Развёрнутые заметки по этой линии сперва писались по-русски (`RELEASE_v0.4.md`). У более поздних линий есть и английские заметки — `docs/RELEASE_v0.4.1.md`, `docs/RELEASE_v0.6.md`, — а у каждой версии теперь есть короткая английская заметка к релизу в `docs/releases/`.
